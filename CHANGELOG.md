# Changelog

## 1.0.0

- 64x64 dashboard with clock, date, current weather and four-day forecast.
- Open-Meteo weather data with configurable timezone.
- Static-image uploads, minute-aligned refresh and unchanged-image detection.
- Current-condition night icons, WMO weather-code coverage and an unknown-code fallback.
- Selectable pixel icon sets with a legacy fallback.
- Dashboard editor, weather-code previews and icon sheets.
- Raspberry Pi startup helpers and optional systemd services.
